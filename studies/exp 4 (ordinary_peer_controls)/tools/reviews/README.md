# Assistant annotation record scripts

These scripts record case-specific assistant judgments after reading the actual saved speech and diagnostic outputs. They are not keyword classifiers, independent raters or general annotation models. They must not label a new run without a new substantive review. The evidence CSVs and semantic-review JSONs preserve the final authoritative labels and exact quotes.

The scripts were authored in the control study working folder during review and are retained here as provenance. They use paths relative to the control study root. They encode judgments for the particular E1/E2 branches named in each script; grouping similar observed cases by sender/recipient is not an inferred intent rule. Followup editorial clarification in the final JSON notes is authoritative. Do not treat rerunning a script as fresh independent validation.
