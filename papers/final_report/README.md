## Reproduce the data and figures

From the repository root, use a Python environment with ReportLab, Pillow, python-docx and pypdf, plus Git and Poppler `pdftoppm`:

```sh
git fetch origin anay/apart-sprint-ring-study sumin/disruption
python3 papers/final_report/tools/collect_report_data.py
python3 papers/final_report/tools/check_late_update.py
python3 papers/final_report/tools/make_figures.py
python3 papers/final_report/tools/write_content.py
python3 papers/final_report/tools/build_report.py --template '/absolute/path/Copy of Apart Research hackathon submission template.docx'
```

The collector reads the pinned contributor Git objects and never imports a model client. If the remote later deletes a branch, retrieve the exact commit SHAs in [SOURCE_MAP.md](SOURCE_MAP.md). It validates 4,184 round price/profit records in 523 complete contributor episodes, rechecks first responses and V18 threshold variants, and verifies prefix identity for plotted pairs. Semantic transcript judgments remain in original reviewed evidence and are not regenerated by a keyword classifier.

`report_content.json` and `tools/write_content.py` hold report text. `tools/build_report.py` edits a copy of the supplied template, checks its SHA-256 and preserves unrelated package parts byte for byte. It emits DOCX and matching Markdown; the PDF is exported using bundled LibreOffice through the document skill renderer. The bundled Codex Python/runtime was used for the published build. Every PDF page was visually inspected. Renderer intermediates remain outside the publication bundle.

Figure 2 retains raw and source-clipped indices separately; the figure plots raw differences. Counts have no naive independence intervals. Figure 3 retains the two quantity histories separately. Source code, raw calls, failures and the earlier three-study foundation remain at their original locations.
